# 机器学习实验报告

## 一、实验实训步骤及数据记录

### 实验一：基于iris数据集的KNN分类模型

1. **数据加载**：
   - 加载iris数据集
   - 数据记录：150个样本，4个特征

2. **数据划分**：
   - 训练集：120个样本（80%）
   - 测试集：30个样本（20%）

3. **模型训练**：
   - 使用KNN分类器，设置K=3

4. **模型评估**：
   - 准确率：100.00%
   - 分类报告：所有类别precision、recall、f1-score均为1.00
   - 混淆矩阵：无错误分类

### 实验二：基于wine数据集的线性回归模型

1. **数据加载**：
   - 加载wine数据集
   - 选择"酒精含量"作为目标变量
   - 数据记录：178个样本，12个特征

2. **数据划分**：
   - 训练集：142个样本（80%）
   - 测试集：36个样本（20%）

3. **模型训练**：
   - 训练线性回归模型
   - 截距：10.9758，12个特征系数

4. **模型评估**：
   - 均方误差（MSE）：0.1857
   - 均方根误差（RMSE）：0.4309

## 二、实验实训结果分析及体会

本次实验成功实现了KNN分类和线性回归模型的训练与评估。KNN分类器在iris数据集上表现完美，准确率100%，说明KNN适合此类特征明显的分类任务；线性回归模型预测酒精含量的MSE为0.1857，误差较小，表明模型拟合效果良好。通过实验，我掌握了分类与回归模型的基本流程，包括数据处理、模型训练和性能评估，同时理解了不同模型的适用场景和评估指标的含义。后续可通过调参进一步优化模型性能。
