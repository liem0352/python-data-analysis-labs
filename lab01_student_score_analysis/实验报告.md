# 学生成绩数据分析实验报告

## 一、实验实训步骤

### 步骤1：准备环境
- 确保安装了Python环境
- 安装必要的库：pandas、numpy
- 创建工作目录并设置为当前工作环境

### 步骤2：创建Python脚本
- 创建名为`student_analysis.py`的Python文件
- 导入必要的库（pandas和numpy）
- 编写数据生成、保存和筛选的功能函数

### 步骤3：生成学生数据
- 使用pandas创建DataFrame对象
- 设置列名为：学生姓名、高等数学、大学英语、体育、高级语言
- 生成10名学生的随机成绩数据（60-100分之间）
- 使用随机种子确保结果可复现

### 步骤4：数据持久化
- 将生成的学生数据写入CSV文件（student_info.csv）
- 设置编码为utf-8-sig以确保中文正常显示
- 不写入索引列，保持数据整洁

### 步骤5：数据读取与验证
- 从CSV文件读取学生数据到新的DataFrame对象
- 打印读取的数据，验证数据完整性和正确性

### 步骤6：数据筛选与分析
- 使用布尔筛选方法找出各科成绩均在80分以上的优秀学生
- 提取优秀学生的姓名信息并输出
- 显示优秀学生的详细成绩数据

### 步骤7：执行程序并观察结果
- 运行Python脚本
- 观察控制台输出的中间结果和最终分析结果

## 三、实训结果分析

### 数据生成与存储分析
- 成功生成了符合要求的10×5二维数据表，包含10名学生的5个字段信息
- 通过numpy的随机数生成功能，模拟了合理的学生成绩分布（60-100分）
- 数据写入CSV文件时使用utf-8-sig编码，确保了中文列名和学生姓名的正确显示
- 从CSV文件读取的数据与原始数据完全一致，验证了数据持久化的正确性

### 筛选结果分析
- 在10名学生中，共有2名学生（学生2和学生6）的各科成绩均在80分以上
- 学生2的成绩表现：高等数学88分、大学英语95分、体育80分、高级语言96分
- 学生6的成绩表现：高等数学98分、大学英语81分、体育84分、高级语言98分
- 优秀学生占总人数的20%，表明样本数据中成绩分布相对合理
- 从整体数据来看，大部分学生在某些科目上表现较好，但能保持所有科目都优秀的学生较少

### 技术实现分析
- 使用pandas的DataFrame对象成功实现了结构化数据的表示和操作
- 通过布尔索引和`.all()`方法实现了多条件组合筛选，代码简洁高效
- 函数化的代码结构提高了程序的可读性和可维护性
- 设置随机种子确保了实验结果的可复现性，便于验证和调试
